Variables:
    Variables are used to store data.its like a container

    Rules:
    1. Allowed Characters: Names can only contain letters (A-Z, a-z), digits (0-9), and underscores (_).
    2. Starting Character: Names must start with a letter or an underscore. They cannot start with a number.
    3. No Spaces: You cannot use spaces inside a variable name.
    4. No Special Characters: Symbols like @, $, %, -, or ! are strictly forbidden.
    5. Reserved Keywords: You cannot use Python's built-in keywords (such as if, for, while, class, or import) as variable names.

1.typecasting
    the process of converting a variable from one data type to another
    1. Explicit Type Casting (Manual)
    2. Implicit Type Casting
        Python automatically converts one data type to another 
        without programmer intervention when it is safe to do so
    Key Considerations
    Data Loss: Converting from a "higher" type (like a float) to a "lower" type (like an integer) will result in data loss, such as losing decimal precision.
    1. Non-Numeric Strings to Numbers
    2. Non-Iterable Types to CollectionsYou cannot cast single, non-iterable values (like integers, floats, or booleans) into sequence types like a list, tuple, or set.

    TypeError means you used the wrong type of object 
    ValueError means the object type is correct, but its actual value is invalid.

3. set
1. Overlapping Items (Intersection)
    This extracts only the elements that exist in both sets.
    1. Using the Intersection Operator (&)
    2. Using the .intersection() Method

2. Subtracting Sets (Difference)
    This removes elements of the second set from the first set. Order matters here
    1. Using the Subtraction Operator (-)
    2. Using the .difference() Method
    
3. Create a New Combined Set
    These methods leave your original sets (set1 and set2) unchanged.
    1. Using the Union Operator (|)
    2. Using the .union() Method
    
4. symmetric difference
    The symmetric difference finds elements that are in either of the sets, but not in both
    1. Using the Symmetric Difference Operator (^)
    2. Using the .symmetric_difference() Method

                    Update:
update = Add everything.
intersection_update = Keep only duplicates.
difference_update = Subtract duplicates.
symmetric_difference_update = Delete duplicates, keep the rest.



update
1. .update() (Union In-Place)Adds all elements from the second set into the first set
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

set1.update(set2)
print(set1)  # Output: {1, 2, 3, 4, 5, 6}

2. .intersection_update()Keeps only the elements that exist in both sets.
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

set1.intersection_update(set2)
print(set1)  # Output: {3, 4}


3. .difference_update()Removes all elements of the second set from the first set.
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

set1.difference_update(set2)
print(set1)  # Output: {1, 2}

4. .symmetric_difference_update()
Keeps elements found in either set, but removes the ones they share.
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

set1.symmetric_difference_update(set2)
print(set1)  # Output: {1, 2, 5, 6}

Selector Categories

Find / select the HTML Element you want to Style

  • Simple Selector
    Based on name,id,class
    1. Element Selector
      eg: p{text-align:center;}
    2. id Selector
      eg: #id1{text-align:center;}
    3. class Selector
      eg-1: .classname{text-align:center;} eg-2: p.classname{color:red;}
    4. grouping Selector
                                  eg : h1,h2,p{
                                text-align:center;
                            }
                            note:
                                1.group the selector to minimize the code
                                2.Seperate each Selector with a comma
      /dd>
  • Combinator Selector
    Specific Relationship Between them
    4 Types
    • descendant Combinator(space)
    • child (>)
    • Next Sibling (+)
    • Subsequent -Sibling (~)

    1. Descendant Combinator 
                                  div p {
                                background-color:yellow;
                            }

                            notes:
                                1. Matches all elements that are descentants of a specified Element
                                2. All <p> element inside <div>
    1. Child Combinator
                                  div > p {
                                background-color:yellow;
                            }

                            notes:
                                1. Matches all elements that are Children of a specified Element
                                (direct children - div -section-p => not allowed , div -p => allowed)
    1. Next Sibling Combinator
                                  div +  p {
                                background-color:yellow;
                            }

                            notes:
                                1. first p element that are placed immediately after <div>
                                (div next vara sudden p tag. not inside not after the first one)
    1. Subsequent -sibling Combinator
                                  div ~ p {
                                background-color:yellow;
                            }

                            notes:
                                1. Select all elements that are next Sibling of a specified Element
  • pseudo-class Selector
    Certain State
                        notes: Used to define Special State of an Element
                    eg:
                        1. Mouse Over
                        2. Visited ,unvisited Links
                        3. get Focus
                        4. valid / invalid /required/optional form elements

                        Syntax: Selector : psuedo-class {
                            property:value;
                        }

                        eg: 
                            a:link { color:blue;}
                            a:visited { color:violet;}
                            a:hover { color:pink;}
                            a:active { color:green;}
                        NOTE:
                        1. hover come after link and visited
                        2. active come after hover

                            a.highlight:hover{color:blue;} => on class
                            div:hover{background:green;} => on div
                            p:first-child{color:blue;} =>  p on first-child for any tag
                            p i: first-child
  • pseudo-Element Selector
    part of an Element
                            Style Specific parts of an Element
                        first letter or line of an Element
                            
      
                                
    1. Insert content before or after element
      2. 
                                
    2. Style the marks of list item

    3. viewbox behind a dialog box
      4. 
                            
    
                            Syntax:
                                selector :: pseudo-Element{property:value;}

                                Only can apply to block level Element <p>
                                note: font-color,background,text-decoration,
                                word spacing , letter spacing,vertical-align,
                                text transform,line-height...
                            Example:
                                p::first-letter{font-size:xx-large;}
                                p::first-line{font-size:xx-large;}
  • Attribute Selector
    Attribute / attribute value 
    Specific attribute/attribute value
    1. css[attribute] Selector
      a[target]{background-color:yellow;}
    2. css[attribute="value"] Selector
      a[target="_blank"]{background-color:yellow;}
    3. apply for title with flower
      css[attribute~="value"] Selector
      a[title~="flower"]{background-color:yellow;}
    4. exact value or follwed by(_)
      css[attribute|="value"] Selector
      [class|="top"]{}
    5. exact value or follwed by(_)
      css[attribute^="value"] Selector
      [class^="top"]{}
    6. change only it found that letter (eg: allow top not top1)
      css[attribute$="value"] Selector
      [class$="top"]{}
    7. Letter match eg: allow test,protein not check
      css[attribute*="value"] Selector
      [class*="te"]{}
    8. Styling Format -without class / ID
      css[attribute*="value"] Selector
      input[ type="text"]{color:green}
